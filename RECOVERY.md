# Running the client

With Node.js installed, run npm start or start-client.cmd. The client binds to localhost:5180. The Windows launcher also supports the portable Node.js runtime in the sibling .client-tools directory.

The maintained application is under dist/. Dependencies and Vite scripts are retained for development. The requests table was reconstructed against the existing authenticated request callbacks.

Original styles available in the upstream repository were restored. Four unavailable assets from the incomplete local archive were omitted from the maintained startup page:

- /dist/assets/client-admin-foundation.css
- /dist/assets/client-reference.css
- /dist/assets/client-calendar.js
- /dist/assets/member-announcements-table.css
